# Модульные тесты

Автоматизированные сценарии проверки структурированные по подсистемам и объектам продукта в виде тестов кодом.

Содержимое каталога — скриптовые тесты OneScript (*.os), запускаются через 1testrunner или OneUnit.
Бинарные файлы тестов здесь не хранятся: дымовые наборы Vanessa-ADD поставляются в составе пакета add (oscript_modules), а собственные тестовые обработки хранятся исходниками в src/tests и собираются в build/out/tests.
