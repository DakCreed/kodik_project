# Код тестовых обработок

Предназначен для хранения исходных текстов тестовых обработок (xUnit / Vanessa-ADD).
На каждую тестовую обработку создается отдельный подкаталог с именем обработки (формат разборки vrunner decompileepf).
Собранные бинарные файлы тестов (.epf) попадают в build/out/tests (артефакт сборки, не хранится в git); сборка — команда «Собрать unit тесты» или vrunner compileepf src/tests build/out/tests.
